# Engineering Deliverables Report

## Project Goal
Build a small NLP comparison framework that demonstrates multiple text similarity methods in one runnable package.

## What was implemented
- Flask web application with a query form
- Prompt filtering and validation
- TF-IDF search
- Embedding-based similarity search
- Vector similarity search
- Gradient descent demo
- Embedding failure analysis

## Verification evidence
- The Flask app imports successfully after aligning module entry points.
- The core comparison functions return structured results for sample queries.
- The UI renders the analysis sections for the user.

## Notes
The current implementation is intentionally lightweight and educational, but it is now packaged in a way that is easier to run, explain, and evaluate.
